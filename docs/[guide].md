# Modding Guide
Documents found in `/docs/` folder serve as a reference for how Isle of Ansur is
built, allowing for non-BCS setup of supported features.

It is also, however, an additional resource for BCS development considering the
editor is meant to streamline the process into more helpful, visual format.

## Supported features
- Themepacks

- Statpacks
- Worldpacks
